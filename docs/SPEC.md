# Garam 제품 명세

> 상태: 초안 v0.1 (2026-10-21)

## 1. 한 줄 정의

**Garam**은 GitHub Desktop처럼 직관적이면서, 다국어 지원을 비롯해 GitHub Desktop이 제공하지 않는 기능까지 갖춘 오픈소스 크로스 플랫폼 Git GUI 클라이언트다.

## 2. 목표와 비목표

### 목표

- **처음 쓰는 사람도 헤매지 않는 UI**: 변경 사항 → 커밋 → 푸시의 기본 흐름이 한 화면에서 끝난다.
- **모국어로 쓰는 Git**: UI와 Git 오류 메시지까지 사용자의 언어로 보여준다. 첫 지원 언어는 한국어와 영어다.
- **안전함**: 데이터를 잃을 수 있는 작업(discard, force push, 브랜치 삭제 등)은 항상 확인을 받고, 가능하면 되돌릴 수 있게 한다.
- **빠름**: 대형 저장소(파일 10만 개, 커밋 50만 개)에서도 UI가 멈추지 않는다.
- **호스팅 중립**: Git 원격이면 어디든 동작한다. GitHub 연동은 부가 기능이다.

### 비목표 (당분간)

- Git의 모든 기능을 GUI로 제공하는 것. 고급 작업은 "터미널에서 열기"로 위임한다.
- 코드 에디터·IDE 기능.
- 모바일 지원.

## 3. 대상 사용자

1. Git을 막 배우는 학생·주니어 개발자. 특히 영어 UI가 부담스러운 사용자.
2. CLI를 쓰지만 diff 확인과 부분 스테이징은 GUI가 편한 개발자.
3. 개발자와 협업하는 디자이너·기획자.

## 4. 지원 환경

| 항목 | 내용                                                                              |
| ---- | --------------------------------------------------------------------------------- |
| OS   | macOS 12+ (주 개발 환경), Windows 10+, Linux (Ubuntu 22.04+ 기준)                 |
| Git  | 시스템에 설치된 git **2.35 이상**. 없거나 버전이 낮으면 설치 안내 화면을 보여준다 |
| 언어 | 한국어(ko), 영어(en). 영어가 원본 언어                                            |
| 테마 | 라이트·다크·시스템 설정 따르기                                                    |

## 5. 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│ [저장소 ▾]   [브랜치 ▾]   [Fetch/Pull/Push 버튼 + ↑↓ 카운트]   │  ← 툴바
├───────────────┬──────────────────────────────────────────────┤
│ [변경 사항|히스토리] 탭 │                                     │
│               │                                              │
│ 파일 목록      │           Diff 뷰어                           │
│ (체크박스로    │   (줄 단위 선택 → 스테이징)                    │
│  스테이징)     │                                              │
│               │                                              │
├───────────────┤                                              │
│ 커밋 메시지    │                                              │
│ [요약]        │                                              │
│ [설명]        │                                              │
│ [커밋 버튼]    │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

- **툴바**: 현재 저장소 선택(드롭다운 + 검색), 현재 브랜치 선택·생성, 원격 동기화 버튼 하나(상황에 따라 Fetch/Pull/Push/Publish로 바뀜).
- **변경 사항 탭**: 왼쪽에 변경 파일 목록과 커밋 입력, 오른쪽에 선택한 파일의 diff.
- **히스토리 탭**: 왼쪽에 커밋 목록(가상 스크롤), 오른쪽에 선택한 커밋의 변경 파일과 diff.
- **설정**: 언어, 테마, Git 사용자 정보(user.name/email), 기본 에디터·터미널, 백그라운드 fetch 주기.

## 6. MVP 기능 범위 (v0.1)

GitHub Desktop의 핵심 흐름을 동등한 수준으로 구현하는 것이 MVP 기준이다.

### 저장소

- 로컬 저장소 추가(폴더 선택 또는 드래그 앤 드롭), 새 저장소 만들기(`git init`)
- 저장소 복제(URL 입력, 진행률 표시, 취소 가능)
- 저장소 목록 관리(추가·제거·최근 사용 순), Finder/탐색기·에디터·터미널에서 열기(저장소별 기본 에디터, Xcode·Android Studio는 프로젝트 파일을 찾아 열기)
- 저장소를 새 창으로 열기(이 창/새 창 묻기, 답 기억하기, 설정에서 바꾸기)

### 변경 사항·커밋

- 작업 트리 상태 표시(추가·수정·삭제·이름 변경·충돌·untracked)
- 파일 단위·hunk 단위·**줄 단위** 스테이징과 언스테이징
- 변경 사항 되돌리기(discard). 확인을 받고, 가능하면 휴지통/백업으로 복구할 수 있게 한다
- 커밋(요약 + 설명), 직전 커밋 수정(amend), 공동 작성자(Co-authored-by) 추가
- 저장소별 작성자: 전역 Git 설정 대신 이 저장소에서만 쓸 이름·이메일을 저장소 설정(`.git/config`)에 저장한다
- 텍스트·이미지 diff, 바이너리 파일 표시, 공백 무시 옵션

### 브랜치

- 브랜치 목록(로컬·원격), 검색, 생성, 전환, 이름 변경, 삭제
- 변경 사항이 있을 때 브랜치를 전환하면 "가져가기 / 현재 브랜치에 stash" 중에서 선택
- 다른 브랜치를 현재 브랜치에 병합

### 원격 동기화

- fetch / pull / push, ahead·behind 카운트 표시
- 새 브랜치 publish(upstream 설정)
- 백그라운드 자동 fetch(주기 설정 가능)
- 인증: git credential helper 사용. 자격 증명이 필요하면 앱 안의 프롬프트로 입력받는다(askpass)

### 히스토리

- 커밋 목록, 커밋 상세(메시지·작성자·변경 파일·diff)
- 커밋 되돌리기(revert), 해시 복사, 브랜치 생성

### 충돌 해결

- 병합·pull 중 충돌 상태 감지와 안내 배너
- 파일별로 "내 것 / 상대 것 사용", 외부 에디터에서 열기, 해결 완료 표시
- 병합 계속 / 중단

### 공통

- 한국어·영어 UI, 런타임 언어 전환
- Git 오류를 사용자 언어의 설명과 해결 방법으로 보여주고, 원문은 "자세히"에 넣는다
- 라이트·다크 테마, 키보드 단축키, 기본 접근성(키보드 탐색, 스크린 리더 레이블)

## 8. 성공 기준 (MVP)

- macOS, Windows, Linux에서 설치 파일로 설치해 위 MVP 흐름을 끝까지 수행할 수 있다.
- 파일 10만 개짜리 저장소에서 상태 새로고침 후 UI 반영이 1초 안에 끝난다(SSD 기준).
- UI 문자열이 모두 번역 키로 관리되고, `ko`와 `en`의 키 누락이 0개다(CI에서 검사).
- 사용자 데이터를 잃게 만드는 버그가 알려진 것 중에 0개다.
