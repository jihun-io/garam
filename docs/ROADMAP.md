# Garam 로드맵

> 각 마일스톤은 "동작하는 앱"으로 끝난다. 완료 조건을 모두 만족해야 다음 단계로 넘어간다.
> 마일스톤 순서는 의존 관계를 따른다. 진행하면서 체크박스를 갱신한다.

## M0. 프로젝트 기반
- [ ] Tauri 2 + React + TypeScript + Vite 프로젝트 생성, pnpm 사용
- [ ] Cargo workspace 구성 (`src-tauri`, `crates/garam-git`)
- [ ] ESLint, Prettier, `cargo fmt`, `clippy` 설정
- [ ] i18next 설정, `en`/`ko` 기본 네임스페이스, 설정에서 언어 전환
- [ ] `docs/GLOSSARY.md` (Git 용어 한국어 번역표)
- [ ] 번역 키 누락 검사 스크립트
- [ ] Rust→TS 타입 바인딩 자동 생성 파이프라인
- [ ] `AppError` 형식과 프론트 오류 표시 컴포넌트
- [ ] git 설치·버전 감지, 미설치 시 안내 화면
- [ ] `TestRepo` 테스트 픽스처
- [ ] GitHub Actions CI (3개 OS)

**완료 조건**: 앱이 실행되고, git 버전이 표시되며, 한국어↔영어 전환이 되고, CI가 통과한다.
