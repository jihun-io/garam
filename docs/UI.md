# Garam UI 개선 계획

> 상태: 초안 v0.1 (2026-10-22). M8의 "설정 화면", "키보드 단축키, 접근성 점검"을 진행하면서 화면 전체를 데스크톱 앱답게 다듬는다.
> 이 문서는 디자인 기준이기도 하다. 새 화면을 만들 때 4장 "UI 규칙"을 따른다.

## 1. 목표

- **진짜 응용 프로그램처럼**: 웹 페이지가 아니라 운영체제에 속한 앱처럼 보이고 동작한다. 커서, 선택, 메뉴, 단축키, 창 테두리가 각 OS의 관례를 따른다.
- **아이콘으로 빠르게 읽힌다**: 글자 기호(`⟳ ↑ ✕ ▾`)를 하나의 아이콘 세트로 바꾸고, 같은 의미에는 같은 아이콘을 쓴다.
- **디테일이 맞는다**: 간격, 크기, 포커스 표시, 툴팁, 빈 화면·로딩 상태가 화면마다 다르지 않다.
- **키보드와 스크린 리더로 끝까지 쓸 수 있다.**

## 4. UI 규칙 (디자인 기준)

### 4.1 커서와 선택

- 버튼, 메뉴, 탭, 목록 항목, 체크박스는 **기본 화살표 커서**다. 손가락 커서는 외부로 나가는 진짜 링크에만 쓴다.
- 텍스트 입력은 I빔, 크기 조절 경계는 크기 조절 커서, 비활성 요소도 화살표(금지 표시 `not-allowed`를 쓰지 않는다).
- 텍스트 선택은 기본으로 막고, 내용(diff, 커밋 메시지, 오류 원문, 경로·해시처럼 복사할 만한 값)과 입력 필드에만 허용한다. macOS의 WKWebView(Safari 엔진)는 접두사 없는 `user-select`를 무시하므로 **항상 `-webkit-user-select`와 함께 쓴다**.
- 웹뷰 기본 오른쪽 클릭 메뉴(새로고침, 요소 검사 등)는 띄우지 않는다. 입력 필드(잘라내기·복사·붙여넣기)와 선택한 텍스트 위(복사)에서만 남기고, 화면이 자기 메뉴를 가진 곳은 그 메뉴가 뜬다(`src/lib/contextMenu.ts`). 개발 빌드에서는 Option(Alt)을 누른 채 오른쪽 클릭하면 기본 메뉴가 떠서 웹 검사기를 열 수 있다.

### 4.2 아이콘

- `@phosphor-icons/react`를 쓰고, 앱 공용 `Icon` 래퍼로 크기(12·14·16·20px, 빈 화면만 32px)와 굵기 규칙을 한곳에서 정한다.
- 의미와 아이콘을 1:1로 정한 표를 `src/components/icons.ts`에 두고 화면에서는 그 이름만 쓴다(예: `Icons.branch`, `Icons.push`).
- 아이콘만 있는 버튼에는 반드시 `aria-label`과 툴팁을 붙인다. 가능하면 `IconButton`을 쓰고, 직접 만들 때는 `padding: 0`과 그리드 가운데 정렬을 준다(브라우저 기본 버튼 여백 때문에 아이콘이 한쪽으로 밀린다).
- 상태색(추가·수정·삭제·충돌)은 아이콘 모양으로도 구별되게 한다(색맹·흑백 대비).

### 4.3 창, 툴바, 메뉴

- macOS: `titleBarStyle: "Overlay"` + 제목 숨김. 툴바 왼쪽에 창 버튼 자리(약 72px)를 비우고, 버튼이 아닌 툴바 빈 곳은 창 끌기 영역(`data-tauri-drag-region`)으로 한다. 툴바를 더블클릭하면 창 확대(OS 설정 따름).
- 메뉴 막대는 **프론트에서 Tauri의 JS 메뉴 API로 만든다**. 메뉴 문구도 번역 키를 거쳐야 하기 때문이다(Rust는 사용자용 문장을 만들지 않는다는 규칙). 언어를 바꾸면 메뉴를 다시 만든다.
- 메뉴 항목의 활성·비활성은 현재 상태(저장소 선택 여부, 진행 중인 작업 등)를 따라간다.
- macOS가 직접 넣는 메뉴 항목(글쓰기 도구, 자동 완성, 받아쓰기, 이모지 및 기호 등)은 앱이 지원하는 언어(`src-tauri/Info.plist`의 `CFBundleLocalizations`)와 앱의 `AppleLanguages` 설정을 따른다. AppKit은 이것을 시작할 때만 읽으므로, 가람은 시작 직전과 언어를 바꿀 때 `AppleLanguages`를 언어 설정에 맞추고(`src-tauri/src/locale.rs`), 설정 화면에서 다시 시작을 권한다.
- 앱 안 버튼과 메뉴 항목이 같은 동작이면 같은 이름과 같은 단축키를 쓴다.
- 모달 대화상자가 열려 있어도 창을 옮길 수 있어야 한다. macOS에서는 대화상자 배경 위에 툴바 높이만큼 끌기 영역을 두고, 그곳을 누르는 것은 대화상자 바깥 클릭으로 치지 않는다(`WindowDragArea overDialog`, `keepOpenWhenDraggingWindow`).

### 4.4 포커스, 툴팁, 상태 표현

- 포커스 표시: 버튼·목록은 2px 바깥 윤곽선, 입력 필드는 테두리 색 + 안쪽 링으로 두께가 겹치지 않게 한다. 마우스 클릭으로는 보이지 않고 키보드 이동에서만 보인다(`:focus-visible`).
- 툴팁: Radix Tooltip 기반 공용 컴포넌트. 약 500ms 지연, 키보드 포커스로도 나타나며, 단축키가 있으면 함께 표시한다(예: "푸시 ⇧⌘P").
- 로딩: 300ms 안에 끝나는 로딩은 아무것도 보여주지 않고, 더 걸리면 자리를 유지한 채 돌아가는 표시와 "불러오는 중…"을 띄운다(`Loading`). 데이터를 기다리는 동안 `return null`로 비워 두지 않는다. 툴바 버튼은 같은 크기의 자리 표시(`ToolbarPlaceholder`)로 자리를 잡아 툴바가 밀리지 않게 한다.
- 빈 화면: 아이콘 + 제목 + 한 줄 설명(`EmptyMessage`), 할 수 있는 다음 행동이 있으면 메뉴와 같은 이름·단축키를 단 버튼(`CommandList`)을 붙인다. 지금 할 수 없는 명령은 숨긴다.
- 알림(화면 오른쪽 아래): 성공은 초록 체크, 오류는 빨간 경고 아이콘으로 같은 틀을 쓴다. 성공 알림은 4초 뒤 사라지되 마우스가 올라가 있는 동안은 기다리고, 오류는 닫을 때까지 남는다.
- 비활성 버튼은 회색 계열로 확실히 구별한다. 강조·위험 버튼도 비활성이면 색을 빼고 회색이 된다(흐린 초록은 눌러도 될 것처럼 보인다).
- 강조·위험 색 위의 글자는 `--color-on-accent`·`--color-on-danger`를 쓴다. 다크 테마에서는 배경이 밝아지므로 흰 글자를 고정하지 않는다.
- 네이티브 `title` 툴팁은 쓰지 않는다. 잘릴 수 있는 값(경로, 커밋 요약)은 `Tooltip whenTruncated`로 실제로 잘렸을 때만 전체를 보여준다.
- 드롭다운은 브라우저 기본 `<select>` 대신 공용 `Select`(Radix Select)를 쓴다. 키보드(화살표, 글자 입력으로 이동, Enter, Escape)는 그대로 동작한다.

### 4.4.1 접근성

- 대비: 본문 글자색(`ink`, `ink-muted`, `link`, `danger`, `added-ink`, `modified-ink`)은 모든 배경(선택된 행 포함)에서 WCAG AA 4.5:1 이상. `ink-faint`는 테두리·비활성·장식용으로만 쓰고 정보를 담은 글자에는 쓰지 않는다. `src/styles/tokens.test.ts`가 지킨다.
- 이름: 여러 줄로 된 버튼은 보이는 글자가 그대로 이름이 되게 하고, 줄 사이에 공백 글자를 둔다(레이아웃에는 영향 없음). `aria-label`로 다른 문장을 붙이지 않는다(음성 제어 사용자는 보이는 글자로 부른다).
- 목록 행: 행(`option`) 안에 다른 컨트롤을 넣지 않는다. 체크 상태는 행의 `aria-checked`로 알리고, 체크 모양은 `CheckMark`(그림)로 그린다.
- 긴 목록·diff는 탭 정지점 하나로 들어가 화살표로 움직인다. 탭으로 수백 번 눌러야 지나갈 수 있는 곳을 만들지 않는다.
- 대화상자를 닫으면 연 곳으로 포커스가 돌아간다. 메뉴 항목에서 열었다면 그 메뉴의 버튼으로 돌아간다(`FormDialog`).
- macOS WebKit은 시스템 설정의 "키보드 탐색"이 꺼져 있으면 Tab으로 텍스트 필드만 오간다(Option+Tab은 전부). 네이티브 앱과 같은 동작이므로 따로 바꾸지 않는다.

### 4.5 움직임

- 팝오버·메뉴·대화상자는 120~160ms 페이드·살짝 확대로 나타난다. 그 외 장식용 움직임은 쓰지 않는다.
- `prefers-reduced-motion`이면 모두 끈다(이미 적용됨).

### 4.6 색과 테마

- 테마: 시스템 따르기(기본) / 라이트 / 다크. `data-theme`으로 강제할 때와 시스템을 따를 때가 **같은 토큰 집합**을 쓰도록 토큰 파일을 정리한다.
- 강조색: 가람 초록(기본), 준비된 색 몇 가지(파랑·보라·주황 등, 라이트·다크 대비를 미리 맞춘 값), 시스템 강조색.
- 시스템 강조색 읽기:
  - macOS: 시스템 설정의 강조색(WebView의 CSS `AccentColor` 지원 여부를 먼저 확인하고, 안 되면 Rust에서 `NSColor.controlAccentColor`)
  - Windows: 사용자 설정의 강조색(레지스트리 `DWM\AccentColor`)
  - Linux: GNOME 47+·KDE는 데스크톱 설정에서, 나머지는 읽을 수 없으므로 가람 초록으로 대신하고 설정에 그 사실을 표시
- 시스템 강조색이 너무 밝거나 어두워 글자 대비(WCAG AA 4.5:1)가 안 나오면 자동으로 명도를 조정한다.

### 4.7 글자와 밀도

- 변경 사항·히스토리 사이드바는 경계를 끌어(또는 포커스 후 ←/→) 너비를 바꾸고, 두 번 누르면 기본값(320px)으로 돌아간다. 너비는 설정에 저장한다. 최소 256px(macOS에서 창 버튼 자리 96px를 빼도 "현재 저장소" 버튼이 최소 너비 160px를 지킴), 최대 560px이고, 오른쪽에는 diff와 툴바의 브랜치·동기화 버튼이 들어가도록 최소 480px를 남긴다. 툴바 버튼은 자리가 모자라면 최소 너비(160px)까지 줄고, 툴바는 넘쳐도 가로 스크롤을 만들지 않는다. 툴바의 "현재 저장소" 버튼은 오른쪽 끝이 항상 사이드바 끝과 맞는다(`--sidebar-actual`). 사이드바 크기 조절 경계는 팝오버·메뉴 아래에 깔려 그 위로는 잡히지 않는다(사이드바 `isolation: isolate`).
- 툴팁으로 감싼 Radix 요소는 툴팁이 `data-state`를 덮어쓰므로, 선택 상태는 `aria-selected`·`aria-checked` 같은 ARIA 속성으로 스타일한다.
- 기준 13px, 작은 글자 11px은 보조 정보에만.
- 브랜치·저장소·파일 이름처럼 길이를 알 수 없는 값은 말줄임표(…)로 줄이고, 주변 문구("에 커밋" 등)는 줄이지 않는다. 잘린 값은 툴팁으로 전체를 보여준다. 긴 값이 패널 폭을 넓히지 않게 그리드·플렉스 항목에 `min-width: 0`을 준다. 툴바 높이 52px(macOS 창 버튼과 높이를 맞춤), 목록 행 28px, 버튼 28px.
- 한 화면 안에서는 간격 토큰(4·8·12·16·24)만 쓴다.

## 7. 설정 화면 구성

앱 안 대화상자. 왼쪽 항목 목록, 오른쪽 내용. 바꾸면 바로 적용하고 저장한다(확인 버튼 없음).

| 항목    | 설정                                                                                                              |
| ------- | ----------------------------------------------------------------------------------------------------------------- |
| 일반    | 언어(시스템 언어 따르기 포함). "시작할 때 마지막 저장소 열기"는 이미 항상 마지막 저장소를 열기 때문에 빼기로 했다 |

| Git     | 사용자 이름·이메일(전역 `user.name`/`user.email`), 새 저장소 기본 브랜치 이름(`init.defaultBranch`)               |
| 연동 앱 | 기본 에디터, 기본 터미널                                                                                          |

- Git 설정은 앱이 따로 저장하지 않고 git config를 직접 읽고 쓴다.

## 8. 진행 단계

각 단계는 앱이 동작하는 상태로 끝나고, 실제 앱(`pnpm tauri dev`)과 라이트·다크·한국어·영어에서 확인한다.

1. **기반** (완료): Phosphor 도입과 `Icon` 래퍼·아이콘 표(`src/components/icons.ts`), 모든 글자 기호 교체, 커서·선택 규칙 적용, 색 토큰 정리(다크 버그 수정, 테마는 `src/lib/theme.ts`가 `data-theme`으로 적용), 포커스 링, 공용 툴팁(아이콘 버튼·커밋 수·파일 상태부터 적용), 팝오버·대화상자 등장 효과
2. **창과 툴바** (완료): macOS 제목 표시줄 합치기(창 버튼 위치 `trafficLightPosition` 18·26, 툴바 왼쪽 여백 96px, 전체 화면에서는 0, 툴바 빈 곳과 툴바 없는 화면 상단 28px가 끌기 영역), 두 줄 툴바 버튼(`ToolbarButton`) 통일, 아이콘 버튼(`IconButton`), 툴바에서 언어 선택 제거, 설정 버튼과 최소 설정 대화상자(일반 > 언어)
3. **설정** (완료): 설정 저장소(Rust `settings.json`, 없는 필드는 기본값으로 채움), 설정 대화상자(일반·모양·Git·연동 앱·동기화), 시작 전에 설정을 읽어 첫 화면부터 적용, 테마·강조색(준비된 5색 + 시스템 강조색, 대비 자동 보정)·diff 글자 크기, 백그라운드 가져오기 주기·기본 에디터·터미널 연결, 예전 언어 설정(webview 저장소) 옮기기
4. **메뉴와 단축키** (완료): 명령 레지스트리(`src/lib/commands.ts`: 화면이 할 수 있을 때만 명령을 등록하고, 메뉴는 그에 따라 항목을 켜고 끈다), JS 메뉴 API로 만든 메뉴 막대(번역, 언어를 바꾸면 다시 만듦, macOS 윈도우·도움말 메뉴 지정), 메뉴 단축키(OS가 처리), 툴팁에 단축키 표시, 단축키 목록 대화상자, 파일 목록의 변경 취소 단축키
5. **화면별 다듬기** (완료): 로딩 표시(`Loading`, 300ms 지연)와 툴바 자리 표시, 빈 화면(`EmptyMessage`, 변경 사항이 없을 때 에디터·터미널·Finder 열기 버튼과 단축키), 비활성 강조·위험 버튼 회색 처리, 다크 테마에서 위험 버튼·체크박스 글자 대비, 알림 틀 통일(아이콘, 마우스를 올리면 자동으로 닫히지 않음), 히스토리 파일 목록을 변경 사항과 같은 상태 아이콘으로, 좁은 창에서 커밋 상세의 파일 목록을 diff 위로 쌓기, 해시 복사 아이콘, 충돌 배너·파일 안내 아이콘, 네이티브 `title` 툴팁 제거(잘린 값에만 툴팁). 파일 상태 아이콘과 커밋 폼 라벨(화면에는 숨기고 스크린 리더용으로 둠)은 1단계에서 이미 정리됨
6. **접근성 점검** (완료): axe-core로 모든 화면(첫 화면, 변경 사항, 충돌, 히스토리, 설정, 피커·메뉴·대화상자)을 라이트·다크에서 점검해 위반 0건, 키보드만으로 파일 선택 → 포함 → 요약 입력 → 커밋, 충돌 파일 선택과 해결 버튼까지 확인. 고친 것: 툴바 버튼 이름(두 줄이 붙어 읽히던 것, 보이는 글자와 다른 이름), 피커 팝오버 이름, 탭 패널 자체가 탭 정지점이던 것, diff 줄마다 탭 정지점이던 것(하나의 정지점 + 화살표, 줄 이름에 번호와 내용), 읽기 전용 diff를 키보드로 스크롤, 메뉴에서 연 대화상자를 닫으면 포커스가 사라지던 것, 파일 행 안의 체크박스 중첩(행이 `aria-checked`로 상태를 알림), 라이트 테마 수정·추가·링크 글자색과 diff 줄 번호 대비(AA), 숨긴 h1. 회귀 테스트: 화면별 axe 검사(`src/test/axe.ts`), 테마 토큰 대비 검사(`src/styles/tokens.test.ts`), 대화상자 포커스 복귀, diff 키보드 이동
   - **남은 확인**: 실제 VoiceOver·NVDA로 읽어 보기, 실제 앱에서 키보드로 저장소 추가·푸시(메뉴 단축키는 OS가 처리하므로 미리보기에서 확인 불가)

## 9. 미리 확인할 위험

- **macOS 제목 표시줄 합치기**: 끌기 영역과 버튼 클릭이 겹치지 않게 해야 하고, 전체 화면에서는 창 버튼 자리를 비울 필요가 없다. 창 버튼 위치는 OS 버전마다 조금 다르다.
- **Windows·Linux 메뉴 막대**: 창 안 상단에 붙으므로 툴바 위에 한 줄이 더 생긴다. Linux는 데스크톱 환경마다 모양이 다르다.
- **시스템 강조색**: Linux 일부 환경에서는 읽을 수 없다. 강조색이 바뀔 때 실시간 반영은 macOS·Windows에서만 목표로 한다.
- **아이콘 번들 크기**: 사용하는 아이콘만 가져오도록(트리 셰이킹) 개별 import를 쓴다.
